# このサーバーの利用ガイドの設計書

- 仕様: `spec.md`

## 利用ガイドの設計の方針

- フォーク元の利用ガイドのページと設定をそのまま土台にし、このサーバーの利用ガイドには、このフォークの機能のページと、このサーバーに合わない所の上書きだけを書く。フォーク元の版を取り込むたびに、利用ガイドの中身も見た目も、その版に合うため
- フォーク元のファイルは、アプリのメニューの項目を足す所だけを変え、利用ガイドのページと設定、公開の作成では変えない
- 公開の作成の方針と手順は、公開の設定の文書（`custom-docs/deploy.md`）に従う
- 利用ガイドとアプリの食い違いは、作りでは防がず、自分の文書の直す順の最後に、このフォークの機能のページを置いて防ぐ

## 利用ガイドの概念

| 概念                       | 意味                                                                                                                                                                                                                                                                                    | 変わるのは                                       | 持たないもの                             |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ | ---------------------------------------- |
| フォーク元の利用ガイド     | フォーク元が書いた利用ガイドのページと、そのサイトの設定（見た目、見出しの作り方、検索、上の帯、サイドバーの群と順）                                                                                                                                                                    | フォーク元                                       | このサーバーの事情                       |
| このサーバーの利用ガイド   | フォーク元の利用ガイドに、このフォークの機能のページを足し、このサーバーに合わない所を上書きしたサイト。合わない所は、置き場所、アイコン、フォーク元の公開先を指すもの（GitHub と編集のリンク、共有したときの印）、操作マニュアルのサイドバー、上の帯の「操作マニュアル」の選ばれた状態 | 仕様書の公開と見た目                             | ページの中身                             |
| このフォークの機能のページ | このフォークで足したり変えたりした 1 つの機能の、使う人向けの説明                                                                                                                                                                                                                       | その機能の仕様                                   | 並び順                                   |
| このフォークの機能の目次   | このフォークの機能のページの一覧。ページごとの題、使う場面の群、フォーク元の機能を変えた機能なら、操作マニュアルの、その機能の説明のページ                                                                                                                                              | ページの足し引き、題や群の変更                   | 群の順、フォーク元のページ               |
| 操作マニュアルのサイドバー | フォーク元の操作マニュアルのサイドバーの群ごとに、フォーク元のページの後ろに、その群のこのフォークの機能のページを足した並び                                                                                                                                                            | フォーク元の群とページ、このフォークの機能の目次 | ページの中身                             |
| 利用ガイドの置き場所       | アプリのサイトの中の、利用ガイドのパス（`/docs/`）と、利用ガイドの中の、操作マニュアルの入口のパス（`manual/`）                                                                                                                                                                         | 仕様書の公開                                     | 公開先のアドレス                         |
| 公開の作成                 | custom-settings の 1 つの版から、公開するサイトの全部のファイル（アプリと利用ガイド）を作ること                                                                                                                                                                                         | 公開の仕組み                                     | ページの中身                             |
| 操作マニュアルを開く項目   | アプリのメニューの項目の 1 つで、このサーバーの利用ガイドの、操作マニュアルの入口を指すもの                                                                                                                                                                                             | 仕様書のメニューの項目                           | 利用ガイドの中身、人ごとのメニューの並び |
| 手元の確認用の起動         | 手元で、アプリと利用ガイドを、公開と同じアドレスの並びで見られるようにした開発用の起動                                                                                                                                                                                                  | 手元の開発の仕方                                 | 利用ガイドの置き場所、公開の作成         |

- 操作マニュアルのサイドバーの群の順とフォーク元のページは、このフォークの機能の目次に書かず、作るたびにフォーク元の利用ガイドの設定から読む。フォーク元が群やページを変えても、同じ並びに従うため
- このフォークの機能の目次に、フォーク元の操作マニュアルのサイドバーにない群の名前があると、作成を止める。黙って落とすと、ページがサイドバーから消えるため
- 利用ガイドの置き場所は 1 か所に書き、このサーバーの利用ガイド、操作マニュアルを開く項目、手元の確認用の起動が、そこから読む
- 利用ガイドの置き場所は、サイトのいちばん上からのパスで書く。利用ガイドの作成の道具は、置き場所とページのパスをつないでリンクを作り、手元の確認用の起動は、アドレスの頭で 2 つの開発用サーバーに振り分けるため
- 利用ガイドは、サイトのいちばん上ではなく、1 つのフォルダの下に置く。いちばん上に置くと、利用ガイドの入口とアプリの入口がぶつかり、利用ガイドとアプリのファイルが混ざり、手元では 2 つの開発用サーバーの内部のファイルの道筋がぶつかるため
- 公開の作成のうち、利用ガイドを作る所は、手元の送信の前の自動確認でも走らせる。フォーク元の更新で作成が止まるようになったことを、公開の前に見つけるため
- 操作マニュアルを開く項目は、フォーク元の項目と同じ作りにし、既定の並びに足すだけにする。人ごとの並びは、フォーク元のメニューの仕組みに任せ、組み替えた並びに足す処理を持たない。フォーク元は、新しい版で足した項目を組み替えた並びに足さない作りで、それに合わせるため
- 手元の確認用の起動は、アプリと利用ガイドの開発用サーバーのどちらかが止まったら、もう片方も止める。片方だけが動き続けると、アプリから利用ガイドが開けないことに気付きにくいため

### 利用ガイドの概念テスト

- 機能を足した人が、その機能のページを書き、このフォークの機能の目次に 1 行足すと、そのページが、操作マニュアルのサイドバーの同じ群の、フォーク元のページの後ろに出る
- フォーク元が「キャラクター」の群を後ろへ動かしたり、群にページを足したりすると、次の作成から、このサーバーの利用ガイドでも同じ並びになり、このフォークの機能のページは、その群の最後に出る
- フォーク元の更新を取り込むと、次の公開から、利用ガイドのフォーク元のページも、取り込んだ版の中身になる
- 参加者が、部屋の中で FABメニューの「表示」の小窓の「操作マニュアル」を押すと、新しいタブで、同じサイトの利用ガイドの、操作マニュアルの入口のページが開く
- FABメニューを組み替えた参加者が、「メニューの編集」の「項目を足す」から「操作マニュアル」を選ぶと、自分のFABメニューにその項目が付く
- 参加者が、「メニューの編集」で「操作マニュアル」を動かしたり外したりすると、次に開いたときも、その人の画面ではその並びのままになる
- 参加者が、ホットバーの枠に「操作マニュアル」を入れて押すと、メニューの項目を押したのと同じく、操作マニュアルの入口のページが開く
- スマートフォン版の画面の参加者のメニューには「操作マニュアル」がなく、「パソコン版の画面を使う」で切り替えると、FABメニューから開ける
- custom-settings に送ると、Cloudflare が公開の作成を呼び、アプリと利用ガイドが一緒に公開される
- 開発する人が、手元の確認用の起動でアプリを動かし、「操作マニュアル」を押すと、アプリと同じアドレスの並びで、手元の利用ガイドが開く。ページを直すと、開いている利用ガイドに映る
