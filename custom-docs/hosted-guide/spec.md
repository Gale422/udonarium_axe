# このサーバーの利用ガイドの仕様書

- 目的: 遊んでいる途中に「これはどうやるのか」と思ったときに、このサーバーで動いている版のアックスの使いかたを、このフォークで足したり変えたりした機能も含めて引けるようにする。フォーク元が公開している利用ガイドは、フォーク元の最新の版に合わせて変わり、このサーバーの版にない機能も載るため
- 読む人: 自分と、このフォークを公開したアックスの部屋で遊ぶ参加者（GM・PL・見学）
- 対象
  - フォーク元の利用ガイド全体（はじめに、操作マニュアル、困ったとき、設置ガイド、リリースノート）の、custom-settings の版の中身
  - このフォークで足したり変えたりした機能のうち、使う人に見えるもの全部の説明。今ある機能も、これから足す機能も含む
- 対象外
  - フォーク元の利用ガイドのページの中身の書き換え
  - 使う人に見えない変更（公開の設定、テストの直しなど）の説明
  - 機能を足したり変えたりした時期と順番。やりたいことから引く形にし、時系列には並べない

## このサーバーの利用ガイドの公開

- 適用範囲: 利用ガイド全体
- アプリと同じサイトの `/docs/` の下に置く。フォーク元の利用ガイドのページは、フォーク元の利用ガイドの中と同じ並びで置く（入口は `/docs/`、操作マニュアルの入口は `/docs/manual/`）
- custom-settings への送信で、アプリと一緒に作られて公開される。仕組みを一度整えた後は、送信のほかに手作業は要らない
- 同じ送信で公開されるアプリの動きと食い違わない。機能を足したり仕様を変えたりする送信には、このフォークの機能のページの直しも含める
- 利用ガイドの中に、このサーバーの公開先のアドレスを書かない。このフォークの機能のページの元の文書は、GitHub で誰でも読めるため

## このサーバーの利用ガイドの見た目

- 適用範囲: 利用ガイドの全部のページ
- フォーク元の利用ガイドと同じ見た目、サイトの名前、上の帯、操作にする（配色、左のサイドバー、右のページの中の目次、検索欄、前後のページ送り、ダークとライトの切り替え）
- フォーク元の公開先を指す、次のものは出さない
  - フォーク元の GitHub へのリンクと、ページを編集するリンク。どちらもフォーク元のリポジトリを指し、このフォークのページはそこにないため
  - 共有したときに出る印（題・説明・画像・アドレス）。公開先のアドレスを書かないと作れないため
- ブラウザのタブのアイコンは、同じサイトにあるアプリのアイコンにする

## このフォークの機能のページの分け方

- 適用範囲: このフォークの機能のページ
- 1 つの機能に 1 ページを充てる
- 操作マニュアルのサイドバーで、フォーク元の操作マニュアルの使う場面ごとの群のうち、その機能に合う群の、フォーク元のページの後ろに並べる。フォーク元にない群は作らない
  - 例: キャラクターの取り込みの機能のページは、「キャラクター」の群の最後に並ぶ
- このフォークの機能のページを開いているときも、操作マニュアルのサイドバーを出し、上の帯の「操作マニュアル」を選ばれた状態にする
- 操作マニュアルの入口のページは、フォーク元のページのままにする。その中のページの一覧の表には、このフォークの機能のページは出ず、サイドバーと検索欄から引く

## このフォークの機能のページ

- 適用範囲: このフォークの機能のページ
- フォーク元の操作マニュアルのページと同じ順で書き、当てはまらない節は省く
  1. 冒頭に、何ができるかと、誰が使えるか（GM・PL・見学）
  2. 開きかたと、操作の手順
  3. 操作で作られるものの中身（取り込みで作られるコマの欄など）
  4. 設定の項目と、その既定値
  5. うまくいかないときの、見えるものと、原因と直しかた
- 使う人が操作するものと、画面で見えるものの名前と情報だけを書く。何のことか分からず、読む人を迷わせるため
  - 書かないものの例: フォーク元とこのサーバーの区別や、機能をどこで足したかという由来、画面に出ない呼び名（「FABメニュー」など）、画面では見分けられない状態の違い、見えない処理の決まり（データの読み取りの規則など）
  - 画面のものは、画面に出る名前で書き、名前の出ないものは、画面の中の位置と見た目で書く（例: 画面左上の丸いボタン）
- 利用ガイドのほかのページへのリンクは、このサイトの中のページへ張る。フォーク元が公開している利用ガイドは、別の版の中身のため
- 書き方は、フォーク元の `website/` の書き方の決まり（フォーク元の `docs/contribution.md` の「websiteの書き方」）に合わせる

### フォーク元の機能を変えた機能のページ

- 適用範囲: フォーク元にある機能の動きを変えた機能のページ
- 操作マニュアルの、その機能の説明へリンクし、リンク先の説明と違う動きだけを書く。違いは、リンク先の説明と比べる形で書き、フォーク元やこのサーバーの名前は出さない

## アプリの操作マニュアルを開くメニューの項目

- 適用範囲: アプリのメニュー
- 項目の名前は「操作マニュアル」で、押すと、このサーバーの利用ガイドの、操作マニュアルの入口のページを新しいタブで開く
- 部屋の中の全員（GM・PL・見学）が使える
- フォーク元のメニューの項目と同じく、FABメニュー（画面の左上の丸いボタンを押すと縦に並ぶメニュー）・GMツール・PLツールに置け、「メニューの編集」で、人ごとに動かしたり外したりできる
- フォーク元のメニューの項目と同じく、ホットバーの枠にも入れられる。枠の種類「メニューの項目」で選ぶか、メニューの項目の右クリックの「ホットバーに入れる」で入れ、枠を押すと、メニューの項目を押したのと同じく開く
- 既定の並び（「メニューの編集」で組み替えていない人の並び）では、FABメニューの「表示」の小窓の、「メニューの編集」の次に置く。遊ぶたびに開く項目ではないため
  - 狭い画面でパソコン版の画面を使っているときだけ出る「スマホ版の画面に戻す」は、フォーク元のまま「表示」の小窓のいちばん下に置き、この項目の下に出る
- スマートフォン版の画面のメニューは、FABメニューの並びと別の、フォーク元が決めた並びなので、この項目は出ない。「パソコン版の画面を使う」で切り替えると、FABメニューから使える
- 「メニューの編集」でFABメニューを組み替えた人の並びには、フォーク元が新しい版で足した項目と同じく、自動では足さない。「項目を足す」の一覧に出るので、そこから足すか、「初期配置に戻す」で既定の並びに戻すと出る
- アプリの表示の言語が英語と韓国語のときは、項目の名前を訳して出す。利用ガイドの本文は日本語だけ
- この項目の使いかたは、このフォークの機能のページとして、操作マニュアルの左の目次の「基本の操作」の群の最後に置く。フォーク元が、FABメニューの「表示」の小窓と「メニューの編集」を、この群の「画面の見かた」のページで説明しているため

## このサーバーの利用ガイドの手元での確認

- 適用範囲: 手元でアプリを動かして確かめるとき
- `npm start` の代わりに使う、アプリと利用ガイドを一緒に動かすコマンドを用意する。そのコマンドで動かしている間は、アプリの「操作マニュアル」の項目から、手元の利用ガイドが開く
- ページを直すと、開いている利用ガイドに、作り直しを待たずに映る
- 公開の作成は、このコマンドとは別の、公開の作成の手順で行う
