# アリアンロッド2E のキャラクターの取り込みの設計書

- 仕様: `spec.md`

## 取り込みの設計の方針

- アックスのコマのデータの形（欄の種類や属性）は変えず、取り込みの途中でデータを運ぶ入れ物（中間の形）だけを広げる。要件は、データを適切にコマに設定することのため
- シートの値は、書かれたまま運ぶ。どの概念も、変な値を見分けて直さない（仕様書「シートの値の扱い」）
- サイトごとの違いは、サイトのデータをアリアンロッド2E のキャラクターにまとめる段に閉じ込め、それより後の段は、どのサイトから来たかを知らない。どちらのサイトから取り込んでも、同じ欄とパレットのコマにするため

## 取り込みの段

| 段 | すること | サイトごとか |
| --- | --- | --- |
| 取ってくる | 貼られたアドレスから、サイトのデータを取ってくる（フォーク元） | フォーク元が、サイトごとの取り方を持つ |
| まとめる | サイトのデータを、アリアンロッド2E のキャラクターにまとめる。キャラクターの全部の値を設定し終えてから、次の段に渡す | サイトごと |
| コマの中身を決める | アリアンロッド2E のキャラクターから、コマの名前・色・ダイスボット・欄・パレットを決め、取り込みの中間の形に入れる | 共通 |
| 画面にコマを作る | 取り込みの中間の形から、アックスのコマを作る | 共通 |

| まとめる | ゆとシートの見分け | 貼られたデータが、ゆとシートのアリアンロッド2E の PC のシートかを見分け、ゆとシートの読み手でまとめたキャラクターを、コマの中身の組み立てに渡す | ゆとシートの見分け方 | 個々の読み方、コマの中身 |

| まとめる | ゆとシートの文字 | HTML の書き方を戻し、ゆとシートの画面に表示されるとおりにした文字 | ゆとシートの文字の書式 | アックスの事情 |
| まとめる | ゆとシートの読み手 | ゆとシートの記録を、ルールの言葉のキャラクターに読み替える。版の違いの補い、取得元の言葉、ダイス数の補い | ゆとシートの版や、人による書き癖 | 欄の並べ方、アックスの書き方 |

| 画面にコマを作る | 取り込みの中間の形（フォーク元） | 取り込みの共通の入れ物。項目にリソースの値（最大値）と設定を、見出しに設定を、省略できる形で足して運ぶ | フォーク元 | ゲームの事情 |
| 画面にコマを作る | アックスの組み立て（フォーク元） | 取り込みの中間の形から、アックスのコマを作る | フォーク元 | ゲームの事情 |
| 画面にコマを作る | 広げた分の組み立て | 中間の形を広げた分を、アックスの欄と属性に直す。リソースの値のある項目はリソースの欄にし、設定は、アックスの画面の設定欄が書くのと同じ属性に書く | アックスの欄の形と属性 | ゲームの事情 |

- まとめる段のほかの段は、どのサイトから来たかを知らない。サイトごとに違う処理（どの項目を読むか、ない値の補い、合計の仕方の決め方、表の並べ方、名前の戻し）は、そのサイトの読み手が持つ
- 2 つのサイトで同じ決まり（数の読み方、手に持つものの見分け）は、両方のサイトの記録や読み手が使う手伝いの概念にし、コマの中身を決める段には置かない
- 欄の案とパレットの案は、お互いを知らない。どちらも、ルールの言葉、参照の名前、アックスの書き方だけを使う
- キャラクターの手は「武器を持つか持たないか」だけを表す（盾と空は、どの合計の仕方でも同じ扱いのため）
- ゆとシートの記録、ゆとシートの文字、キャラクター保管所の記録、シートの値の読み方、アックスの書き方、広げた分の組み立ては、アリアンロッド2E を知らない。ほかのシステムの取り込みでも使えるようにするため

### 取り込みの概念テスト

- ゆとシートの文字が、記録の文字を、ゆとシートの画面に表示されるとおりの文字に読む
- ゆとシートの読み手が、ゆとシートの記録を、アリアンロッド2E のキャラクターに読み替える
- キャラクター保管所の読み手が、キャラクター保管所の記録を、アリアンロッド2E のキャラクターに読み替え、ない値をルールの計算で補う（判定の基本のダイス数は、アリアンロッド2E の一覧が持つ）
- どちらのサイトの読み手も、手に持つものの見分けで、手が武器を持つかを決めて、キャラクターに設定する
- どちらのサイトの見分けも、そのサイトの読み手でまとめたキャラクターを、コマの中身の組み立てに渡す
- アリアンロッド2E の一覧が、スキルのタイミングと判定を分類する
- 参照の名前が、スキルの置き場と、シートのデータから作る名前を決める
- 攻撃の組み合わせが、手と合計の仕方から、命中とダメージの行の組を決める
- 欄の案が、キャラクターと置き場から、見出しと項目と設定を並べる
- パレットの案が、スキルの置き場と行の組から、パレットの文を書く
- アックスの書き方が、名前を参照で読める名前にし、参照や操作の行の形を書く
- コマの中身の組み立てが、どのサイトから来たかを知らずに、キャラクターだけから、中間の形を作る
- 広げた分の組み立てが、リソースの値のある項目をリソースの欄にし、項目と見出しの設定を、アックスの属性に直す

## 取り込みの処理の流れ

1. 利用者が、どちらかのサイトのキャラクターのアドレスか、データを貼る
2. アックスの取り込みが、データのアドレスに直して取ってくる（ゆとシートは `mode=json`、キャラクター保管所は `<番号>.js`）
3. アックスの形式の見分けの中で、そのサイトの見分けが、アリアンロッド2E のシートかを見分ける
   - ゆとシートの見分けは、ゆとシートの汎用の読み取りより先に見分ける
   - キャラクター保管所の見分けは、キャラクター保管所の読み取り（フォーク元の専用の読み取りを含む）より先に見分ける
4. 見分けが、そのサイトの読み手でキャラクターにまとめ、コマの中身の組み立てに渡す
5. コマの中身の組み立てが、参照の名前、攻撃の組み合わせ、欄の案、パレットの案をつなぎ、中間の形に、名前・色・ダイスボット・欄・パレットを入れる
   - 中間の形のリソース・パラメータ・メモ・参照元は使わない。アックスの組み立てが同じ名前の欄を別に作り、重なるため
6. アックスの組み立てがコマを作り、広げた分の組み立てが、リソースの値と設定を、欄と属性に直す
