# ゆとシートのアリアンロッド2E の取り込みの仕様書

- 目的: ゆとシートのアリアンロッド2E のキャラクターのアドレスをアックスに貼ると、アックスの機能を使って全部の行がそのまま動く、欄とチャットパレットを持つコマができる
- 要件は、ゆとシートのデータを適切にコマに設定することで、コマの機能は広げず、アックスに元からある欄の種類と設定だけを使う
- 頼る事実は、リポジトリの外の資料にあり、本文で資料の見出しを指すときは、頭に「資料」と付ける
  - ゆとシート: `udonarium-axe/_reference/ytsheet-ar2e.md`
  - アックス: `udonarium-axe/_reference/axe-chat-palette.md`
  - 本文の「見本」は、ゆとシートの資料の「見本で見つかったゆとシートのアリアンロッド2E の書き方の幅」に書いた、見本のフォルダ（`udonarium-axe/_reference/ytsheet-ar2e-samples/`）の中のシートで確かめた事実

## 取り込みの対象

- 適用範囲: 貼られたデータ全体
- 対象: ゆとシートのアリアンロッド2E の PC のシート。`sheetURL` が `/ar2e/` を含み、`type` がないもので見分ける
- 対象外のシート（エネミーとギルドのシート、ゆとシートのほかのシステム）は、今までどおり、アックスの汎用の読み取りで取り込む
- 取り込まないもの
  - 自作のパレット（`chatPalette`）。パレットは、いつもシートのデータから作り、自作のパレットを使いたい人は、ゆとシートのコマ出力（zip）を使う
  - 画像。取り込んだ後に手で設定する
  - 装備の欄、追加ステータス（`unitStatus`）、既定値
  - スキルの使用回数の制限（「シーン1回」など）を数えるリソースの欄。制限の文は、スキルの説明に書かれたまま載る
- 値は取り込んだ時点のもので、成長したら取り込み直す
- 取り込み画面の案内の文と対応表は、フォーク元のまま変えない。コマを作る処理に要らないため

## ゆとシートの値の扱い

- 適用範囲: シートから読んでコマに載せる全部の値
- 書かれた値は、加工せずに、書かれたまま載せる
  - 変な値（例: 「toString」というスキル名）でも、書かれたまま表示されていればよく、変な値のせいで変なコマや動かないパレットの行ができても、シートの値のせいとして扱う
  - ただし、取り込みの処理が値のせいで壊れるのは、不具合として直す
- 加工するのは、次のものだけで、それぞれの見出しで決める
  - ゆとシートの画面に表示されるとおりに戻す: 「ゆとシートの文字の読み方」（HTML の書き方と前後の空白）、「スキルの取得元の言葉」、「スキルの説明」（0 か空のコストの「―」）
  - 欄の名前の全角の英数字と記号を、半角にする: 「シートのデータから作る名前」
  - アックスの取り込みに共通の受け入れ方に従う: 「コマの名前と色の読み方」（コマの名前と色の前後の空白を除き、色の形を確かめる）

## ゆとシートの値の読み方

- 適用範囲: シートから読む全部の値
- 文字: 「ゆとシートの文字の読み方」で読む
- 数: 10 進の数として読み、読めないときは「なし」
  - 小数も読む。見本に、行動値が小数のシートがある
  - 「1e+20」のような 10 進の数でない書き方と、有限の数にならないもの（「Inf」など）は、読めないものとして「なし」にする。ゆとシートは、大きな値を計算した結果をこの形で書く
  - 数の欄の値が読めないときは、欄の値を空にする。アックスの数値の欄は数しか表示できないので、書かれた文字はコマに残らない
    - 見本では、数として読む値のうち、数でないのはスキルのコストの「-」だけで、数にして書き方が変わる値もない。ゆとシートが計算して書く値か、作成画面の数しか入らない欄の値のため
    - コストの文字は、スキルの説明に書かれたまま載る
- 「なし」の書き方: 「―」「ー」「-」。アリアンロッド2E の表で、何もないことを表す書き方で、手に持つものの見分けと、タイミングの見出しの並びで使う
- 見分け方を書いていない値は、項目の値をそのまま読む

### ゆとシートの文字の読み方

- 適用範囲: シートから読む全部の文字
- HTML の書き方を戻す
  - ゆとシートと同じ順に、`&amp;` を `&` に、`&quot;` を `"` に戻してから、`&lt;br&gt;` を改行にする
    - 改行の書き方は、ゆとシートと同じく、大文字小文字を区別しない（資料「ゆとシートの文字の書き方」）。そのため、手で「&lt;br&gt;」と書いた所（データでは `&amp;lt;br&amp;gt;`）も、ゆとシートと同じく改行になる
  - 残りの書き方のうち、XML の 5 つ（`&lt;` `&gt;` `&apos;` など）と番号の書き方（`&#9733;` など）を、元の文字に戻す。ゆとシートの画面で、ブラウザが戻すもの
  - ほかの名前の書き方（`&hearts;` など）は、書かれたまま残す。見本にはない
  - 次の所は、ブラウザの戻し方と違う。ブラウザと同じに戻すには HTML の文字の名前の表が要り、アックスの起動時に読む量が、取り込みを使わない人も含めて増えるため。どれも見本にはない
    - `;` のない書き方と、大文字の名前（`&LT;` など）は、戻さずに書かれたまま残す
    - 128〜159 の番号は、ブラウザは「€」などにするが、こちらは見えない制御文字にする
    - 改行やタブの番号の書き方（`&#10;` `&#13;` `&#9;`）は、ブラウザは空白として表示するが、こちらは本物の改行や制御文字にする。1 行の欄にあると、それを載せたパレットの行が割れたり、参照で読めなくなったりするが、シートの値のせいとして扱う
- ゆとシートの書き方（リンク、ルビ、太字、表、見出しなど）は、書かれたまま残す
  - 例: 別のシートへのリンク `[名前#シートの番号]`（見本の、コネクションの名前と所属ギルドにある）は、そのまま載り、リンク先のシートの番号も残る。アックスにはこのリンクの機能がないので、どう載せてもリンクにはならない
- 1 行の欄（複数行の欄以外）は、データの前後の、半角の空白・タブ・改行の文字（LF と CR）だけを、HTML の書き方を戻す前に除く
  - ゆとシートの画面（ブラウザ）でも、これらは表示されないため（資料「ゆとシートの画面で表示されない前後の文字」）
  - ほかの文字（全角の空白、改ページの文字など）は、画面に表示されるので、除かずに書かれたまま残す。見本に、全角の空白 1 文字だけの名前のスキルがある
  - 戻す前に除くので、改行の書き方（`&lt;br&gt;`）による前後の改行は、画面と同じく残る
- 効果文や所持品などの中身は読み取らず、書かれたまま載せる

#### 参照元のアドレスの読み方

- 適用範囲: 参照元（`sheetURL`）
- HTML の書き方を戻さない。ゆとシートも、項目名が `URL` で終わる欄は変換しないため（資料「ゆとシートの文字の書き方」）
  - 前後の文字は、「ゆとシートの文字の読み方」の 1 行の欄と同じく除く

### コマの名前と色の読み方

- 適用範囲: コマの名前と色
- 名前: `namePlate`、なければ `name`
  - コマに載る名前は、アックスの組み立てが前後の空白（全角の空白も含む）を除いたものになり、除いて空なら「インポートキャラクター」になる（資料「アックスの取り込み」）。そのため、`namePlate` が全角の空白だけのシートは、`name` に戻らず「インポートキャラクター」になる（見本にはない）
- 色: `nameColor` を `,` で区切った最初の色を、アックスの取り込みに共通の受け入れ方で使う。前後の空白（全角の空白も含む）を除き、`#rgb` か `#rrggbb` の形のときだけ色にする（資料「アックスの取り込み」）

### 能力値と判定の値の読み方

- 適用範囲: 能力値と判定の値
- 能力値: 資料「キャラクターの能力値の項目」の `stt<記号>Base`（基本値）と `stt<記号>Total`（能力値）
- 能力値の判定: `roll<記号>Dice`（ダイス数）と `roll<記号>`（固定値）
- 特殊な判定: 資料「キャラクターの特殊な判定の項目」の `roll<記号>Dice` と `roll<記号>`

#### ダイス数がない特殊な判定のダイス数

- 適用範囲: シートにダイス数がない特殊な判定（古いシート）
- ゆとシートの計算と同じく、元の能力値の判定のダイス数に、足すダイス数（`roll<記号>DiceAdd`、なければ 0）を足す

### 戦闘とリソースの値の読み方

- 適用範囲: 戦闘とリソースの値

| 値 | 元のデータ |
| --- | --- |
| HP、MP、フェイト | `hpTotal`、`mpTotal`、`fateTotal` |
| フェイト使用上限 | `fateLimit` |
| 行動値、移動力 | `battleTotalIni`、`battleTotalMove` |
| 物理防御力、魔法防御力 | `battleTotalDef`、`battleTotalMDef` |
| 命中のダイス数と合計 | `battleDiceAcc`、`battleTotalAcc` |
| 攻撃力のダイス数と合計 | `battleDiceAtk`、`battleTotalAtk` |
| 回避のダイス数と値 | `battleDiceEva`、`battleTotalEva` |
| 右手の命中と攻撃力 | `battleTotalAccR`、`battleTotalAtkR` |
| 左手の命中と攻撃力 | `battleTotalAccL`、`battleTotalAtkL` |

### 手に持つものの読み方

- 適用範囲: 右手と左手（`armamentHandR…`、`armamentHandL…`）
- 名前の欄は、空か「なし」の書き方かだけを見て、名前の文字（「盾」「素手」など）からは、武器かどうかを見分けない。武器かどうかは、種別と攻撃の値で見分ける
  - ゆとシートの閲覧画面は種別だけで見分けるが、見本には種別が空欄の武器を持つ人が多いので、攻撃の値でも見分ける
- 武器を持つ手: 名前が空でも「なし」の書き方でもなく、次のどちらかの手。武器の名前は、名前の欄
  - 種別が書かれていて、「盾」でも「なし」の書き方でもない
  - 種別が空か「なし」の書き方で、攻撃の値が 0 でない数
- それ以外の手（空の手、盾の手、種別も攻撃の値も空の手）は、武器を持たない手

### 右手と左手の合計の仕方の読み方

- 適用範囲: 全キャラクター
- `handedness` の `1` 合計しない、`2` 両手を合計、`3` 命中のみ合計、`4` 全部表示
- ないときは「合計しない」

#### 右手と左手の値がないキャラクターの合計の仕方

- 適用範囲: 右手の命中の値（`battleTotalAccR`）がないキャラクター（古いシート）
- 「両手を合計」として読む

### 番号の付いた行の読み方

- 適用範囲: スキル・誓約・コネクションの行
- 行の数の項目に書かれた数までの行を読む
- 名前のない行は読まない（欄にもパレットにも作らない）

### スキルの値の読み方

- 適用範囲: スキルの行（`skill{N}…`。行の数は `skillNum`、なければ `skillsNum`）
- 名称、Lv、タイミング、判定、対象、射程、コスト、使用条件、分類、効果は、文字として読む
- コストの数: コストの記録の値が 10 進の数として読めて（「ゆとシートの値の読み方」の数）、整数のときだけ、その数
  - 記録の値は、HTML の書き方を戻す前のもの。`&#52;` のような変な書き方では、表示のコスト「4」と食い違って数にならないが、シートの値のせいとして扱う
  - 見本に、コストを「-」と書く人がいる。数ではないので、コストの数はない

#### スキルの取得元の言葉

- 適用範囲: スキルの取得元（`skill{N}Type`）
- 記号は、ゆとシートの閲覧画面と同じ言葉にする
  - `general` 一般、`race` 種族、`style` 流派、`faith` 天恵、`geis` 誓約、`add` 他スキル、`another` 異才
  - `power` は「パワー」。`classMainLv1` があれば「パワー（そのクラス名）」
- 記号でないもの（クラス名）は、そのまま

### 誓約とコネクションの値の読み方

- 適用範囲: 誓約の行（`geis{N}…`）とコネクションの行（`connection{N}…`）
- 行の数: 誓約は `geisNum`、なければ `geisesNum`。コネクションは `connectionNum`、なければ `connectionsNum`
- 誓約: 名前、成長点（`Cost`、数）、恩恵・束縛など（`Note`）
- コネクション: 名前、関係（`Relation`）、備考（`Note`）

### 携行品とプロフィールの値の読み方

- 適用範囲: 携行品とプロフィールの値

| 値 | 元のデータ |
| --- | --- |
| 所持金 | `moneyTotal` |
| 携行品・所持品 | `items` |
| PL | `playerName` |
| CL | `level` |
| 種族 | `race`。`free` のときは `raceFree` |
| 性別、年齢 | `gender`、`age` |
| メインクラス、サポートクラス、称号クラス | `classMain`、`classSupport`、`classTitle` |
| 所属ギルド | `guildName` |
| 容姿・経歴・その他メモ | `freeNote` |
| 参照元 | `sheetURL` |

## アックスに載せる文字

- 適用範囲: コマに載せる全部の文字（コマの名前、欄の名前と値、パレットの文字）
- 《》は直さない
  - スキルの説明を発言すると、文の中の《名前》は、アックスの演出の印やルビとして読まれる。例: 効果文の《ファイアボルト》は、演出の一覧に同じ名前があれば、送ったときに演出が出る（見本の効果文に多い）
  - 説明で演出を出したい人も、そのまま使えるようにするため。勝手に置き換えるほうが問題になる
- スキルの説明の 1 行目と、パレットの行では、スキル名と武器名を ≪≫ で囲む
  - シートの文字を置き換えるのではなく、こちらが付ける囲みで、中の名前は書かれたまま
  - 《》で囲むと、スキルと同じ名前の演出（例: ファイアボルト）が、その行を送るたびに出るため
- `{` `}` は直さない
  - パレットのスキルの説明の行で説明を発言すると、文の中の `{名前}` はアックスの参照として読まれる。見本の効果文の `{筋力}` は筋力の値になり、`{CL×3＋2}` は読めないので空になる（パレットから送る行では、アックスは読めない参照を空にするため。資料「アックスの参照」）
  - ユドナリウムの系統の書き方として、作者が参照のつもりで書いたものもありうるため
- 操作の印（語の頭の `:` と `：`、`&` と `＆`、`t:`、`&&…-`）は直さない
  - パレットから送る文（スキルの説明、スキル名、武器名）に操作の印があると、送ったときにリソース操作やバフとして読まれる。見本の効果文にある語の頭が `:` の語（例: `:CL5以上で取得可能…`）は、どれもコマにない名前か、演算の印がないので、送っても何も起きない。`&` や `t:` で始まる語は、見本にはない
  - 動くのはコマのリソース操作やバフで、結果はチャットに残り、その場で直せるため。`{` `}` の扱いと、アックスのほかの取り込み（外部の文字をそのままパレットに入れる）ともそろう
- 改行は直さない
  - ゆとシートでは、1 行の欄にも改行が入りうる（`<br>` と書いた所。見本の名前・タイミング・判定・関係の欄にはない）。1 行の欄（名前、タイミング、判定など）に改行があると、それを載せたパレットの行が割れて動かないが、シートの値のせいとして扱う
  - 割れた後ろの行が `//名前=値` の形なら、アックスのパレットの変数として読まれ、同じ名前の欄より先に参照に使われる。パレットの画面には変数の行も薄い字で見えるので、その場で消せる

## シートのデータから作る名前

- 適用範囲: シートのデータから作る欄の名前（スキルの項目、タイミングの見出し、誓約の見出し、コネクションの見出し）
- 直す前の名前は、「ゆとシートの文字の読み方」で読んだもの
- 全角の英数字と記号（U+FF01〜FF5E）を、半角にする
  - アックスの参照は、参照の名前だけを半角に直してから比べ、欄の名前は半角に直さないため（資料「アックスの参照」）。直さないと、その名前を指すパレットの行が動かない
  - 見本のスキル名に多い、ふつうの書き方のため（例: 「トレーニング：精神」→「トレーニング:精神」）
- ほかは直さず、重なっても名前を変えない（「重なった名前」）。次の名前は、その名前を指すパレットの行が動かないが、シートの名前のせいとして扱う
  - 終わりが `^` のスキルの名前。アックスが、参照の終わりの `^` を最大値の印として読むため。参照の終わりに来るのはスキルの項目の名前だけなので、タイミングの見出しの名前は、終わりが `^` でも動く
  - `{` `}` や改行を含む名前
  - `\n`（逆斜線と n）を含む名前。パレットの行を押すと、アックスがこの 2 文字を改行にするため
  - 空白だけの名前（見本に、全角の空白だけの名前のスキルがある）。見出しをたどる参照が、空白だけの段を飛ばして親の見出しを指すので、その名前のスキルの説明の行は空の発言になる（資料「アックスの見出しをたどる参照」）
- スキルの説明の文の中の名前は、直さない（書かれたまま）

### 重なった名前

- 適用範囲: シートのデータから作る名前のうち、ほかの名前と重なるもの
- 重なる: アックスの参照が、2 つの名前を同じ名前と見なすこと
  - 名前だけの参照は、欄の名前を書かれたまま比べる（資料「アックスの名前だけの参照」）
  - 見出しをたどる参照は、欄の名前の前後の空白（全角の空白も含む）を除いて比べるので、前後の空白だけが違う名前も重なる（資料「アックスの見出しをたどる参照」）
- 名前を変えない
- 重なると動かなくなるパレットの行
  - 同じタイミングの見出しの中に、同じ名前のスキルが 2 つ以上あると、そのスキルたちの説明の行（見本にある）。見出しをたどる参照は、同じ見出しに同じ名前が 2 つあると、どちらを指すか決まらないため
  - タイミングの見出しの名前が、前後の空白だけ違う（例: 「メジャー」と「メジャー　」。「スキルのタイミングの分け方」で別の見出しになる）と、両方の見出しのスキルの説明の行（見本にはない）
  - 決まった項目の名前（「取り込んだコマの欄」の表に書いた項目の名前）か「目標値」と同じ名前があると、その名前を名前だけで読む行のすべて（見本にはない）
    - 例: 「HP」という名前のスキルがあると、HP を使う行のすべて
    - 名前だけの参照は、コマ全体で同じ名前が 2 つあると読めないため
    - 「目標値」は、同じ名前の欄があると、チャットの目標値より先に欄が答えるため
- 重なっても、決まった項目の設定（「欄の項目の設定」）は、決まった項目にだけ付ける

## 取り込んだコマのチャットパレット

- 適用範囲: パレット全体
- 見出しの並び: 判定 → 判定（目標値） → 受動判定 → 受動判定（目標値） → リソース操作 → バフ操作 → 能動判定 → スキル
  - 戦闘外で使うことの多い判定を上に置き、戦闘中に使う行を近づける
  - 受動判定の後に HP を減らす、能動判定の前後にバフを付ける、が近くでできる
- 見出しの行: `//--- 見出し`。見出しのかたまりの間に空行
  - 見出しの行は、アックスのパレットの変数の書き方（`//名前=値`）に当てはまらない形にする。`//---` の後に `=`（全角も。間の空白はあってもなくてもよい）が続くと、名前が `---` の変数として読まれるため
- リソースの操作（`:` の行）には、すべて `LZ` を付ける。0 と最大値の間に収め、逆向きの変化を止めるためで、項目の設定に左右されない
- 行は、パレットの変数を使わず、欄を参照する
  - 使う人が、欄と同じ名前のバフを付けると、その間は、その名前を名前だけで読む参照が、読めずに空になる（資料「アックスの名前だけの参照」）。そうなった行は、振り方が壊れて振られないだけで、値は変わらない
  - ただし、値を置き換える行は、値が壊れるので、見出しをたどる参照で書く（「リソース操作の見出しのかたまり」）
- `&R-`（バフの残りを減らす）の行は作らない。行動順でラウンドを進めると自動で減り、二重になるため
- 判定の振り方: `{ダイス数の項目}D6+{固定値の項目}`

### 判定の見出しのかたまり

- 適用範囲: 判定、判定（目標値）
- 判定の並び: 筋力〜幸運、トラップ探知、トラップ解除、危険感知、エネミー識別、アイテム鑑定、魔術判定、呪歌判定、錬金術判定
- 行の名前: 能力値の判定は「【筋力】判定」、特殊な判定は「トラップ探知判定」「魔術判定」など（判定で終わる名前はそのまま）
- 見出し「判定」: 比べる値を `?` にした行（`>=?`）
- 見出し「判定（目標値）」: 比べる値を `{目標値}` にした行（`>={目標値}`）
- 2 つの見出しの行は交互に並べない。使わないほうを見出しごと消せるようにするため

```text
//--- 判定
{筋力判定ダイス}D6+{筋力判定}>=? 【筋力】判定
…
//--- 判定（目標値）
{筋力判定ダイス}D6+{筋力判定}>={目標値} 【筋力】判定
…
```

### 受動判定の見出しのかたまり

- 適用範囲: 受動判定、受動判定（目標値）

```text
//--- 受動判定
{回避ダイス}D6+{回避}>=? 回避判定
:HP-(-{物理防御力})LZ 物理ダメージ適用（(の後にダメージを書く）
:HP-(-{魔法防御力})LZ 魔法ダメージ適用（(の後にダメージを書く）
:HP-LZ 貫通ダメージ適用（-の後にダメージを書く）

//--- 受動判定（目標値）
{回避ダイス}D6+{回避}>={目標値} 回避判定
:HP-({目標値}-{物理防御力})LZ 物理ダメージ適用
:HP-({目標値}-{魔法防御力})LZ 魔法ダメージ適用
:HP-{目標値}LZ 貫通ダメージ適用
```

### リソース操作の見出しのかたまり

- 適用範囲: リソース操作
- 所持品は読まないので、ポーションの行はいつも作る
- 全回復の行の最大値は、見出しをたどる参照（`{リソース/基本/HP^}`）で読む
  - 名前だけの参照（`{HP^}`）だと、使う人が「HP」という名前のバフを付けたときに読めずに空になり、`:HP=LZ` になって HP が 0 になるため（「取り込んだコマのチャットパレット」）
  - 見出しをたどる参照は、バフの名前に邪魔されない

```text
//--- リソース操作
:フェイト-1LZ フェイト使用
:HP={リソース/基本/HP^}LZ HP全回復
:MP={リソース/基本/MP^}LZ MP全回復
:HP+2D6LZ HPポーション
:MP+2D6LZ MPポーション
```

### バフ操作の見出しのかたまり

- 適用範囲: バフ操作
- 付ける行と外す行を交互にせず、かたまりで並べる（空行で区切る）
  1. 自分用: 値を動かすバフと覚え書きのバフの書き方の例、外す行、まとめて外す行
  2. 対象用（`t&`）: 付ける行と外す行
  3. バッドステータスを付ける行
  4. 回復のタイミングがアックスの消えるタイミングに合わないバッドステータスを外す行

```text
//--- バフ操作
&!バフ名/項目/+/量/R数 値を動かすバフ
&バフ名/効果/R数 覚え書きのバフ
&バフ名- バフを外す
&*デバフ- バッドステータスをすべて外す
&*- バフとバッドステータスをすべて外す

t&!バフ名/項目/+/量/R数 対象に値を動かすバフ
t&バフ名/効果/R数 対象に覚え書きのバフ
t&バフ名- 対象のバフを外す
```

#### バッドステータスの行

- 適用範囲: バッドステータス
- 付ける行には、どれも `/デバフ` を付ける。`&*デバフ-` で外せるようにするため
- 回復のタイミングがアックスの消えるタイミングに合うものは、消えるタイミングを付け、残り 1 で付ける
- 合わないものは、消えないバフとして付け、外す行を作る
- 毒と衰弱は、ラウンドの終わりごとに HP を「強さ×5」減らすバフ（ユーザーのエネミー作成ツールと同じ量。道具の場所は `udonarium-axe/_reference/README.md`）で、行の `n` を、使う人が強さに書き換える
- 部屋の状態異常の一覧に同じ名前があると、効果を空にした付ける行は、一覧の中身（効果の文、動かす値、色、絵文字）で付く（アックスの決まり。資料「アックスのバフ」）
  - 取り込みでは、部屋の一覧を上書きしない。部屋の一覧は、卓ごとに書き換えて使うもののため
  - 新しい部屋の初めの一覧には「恐怖」（効果の文「命中-2」、紫、😱）がある。アリアンロッドの恐怖として付けたい卓は、部屋の一覧の「恐怖」を書き換えるか消す
  - 毒と衰弱の行は、値を動かすバフ（`&!`）なので、部屋の一覧を見ない

| バッドステータス | 回復のタイミング | 付ける行 | 外す行 |
| --- | --- | --- | --- |
| 放心 | クリンナップ | `&放心//1/ラウンド終了/デバフ 放心（クリンナップで回復）` | |
| 逆上 | クリンナップ | `&逆上//1/ラウンド終了/デバフ 逆上（クリンナップで回復）` | |
| ノックバック | クリンナップ | `&ノックバック//1/ラウンド終了/デバフ ノックバック（クリンナップで回復）` | |
| スタン | 行動の権利を得たとき | `&スタン//1/手番開始/デバフ スタン（行動の権利を得たときに回復）` | |
| 恐怖 | メインプロセス終了時 | `&恐怖//1/手番終了/デバフ 恐怖（メインプロセス終了時に回復）` | |
| 縛鎖 | セットアップ終了時 | `&縛鎖//none/デバフ 縛鎖` | `&縛鎖- 縛鎖の回復（セットアップ終了時）` |
| スリップ | ムーブを使ったとき | `&スリップ//none/デバフ スリップ` | `&スリップ- スリップの回復（ムーブを使ったとき）` |
| 威圧 | マイナーを使ったとき | `&威圧//none/デバフ 威圧` | `&威圧- 威圧の回復（マイナーを使ったとき）` |
| 狂戦士化 | マイナーを使ったとき | `&狂戦士化//none/デバフ 狂戦士化` | `&狂戦士化- 狂戦士化の回復（マイナーを使ったとき）` |
| 毒 | 効果参照 | `&!毒/:HP/+/0~-(n*5)/none/発生:ラウンド終了/デバフ 毒(n)（nを書き換える）` | `&毒- 毒の回復` |
| 衰弱 | 効果参照 | `&!衰弱/:HP/+/0~-(n*5)/none/発生:ラウンド終了/デバフ 衰弱(n)（nを書き換える）` | `&衰弱- 衰弱の回復` |

### 能動判定の見出しのかたまり

- 適用範囲: 能動判定
- スキルを使わない、元からある命中判定とダメージの行だけ
- どの手の行を作るかは「能動判定の手の組み合わせ」
- 命中判定は、比べるのが受ける側なので、`>?` の 1 種類
- ターゲットなしで振る（`t:` を付けない）。`t:` を付けると、ターゲットを選んでいないときに振られないためで、ターゲットなしの結果も、受ける側の `{目標値}` に入る
- 命中判定の行をすべて並べた後に、ダメージの行を並べる
- 行の形
  - 命中判定: `{命中ダイス}D6+{命中の項目}>? 命中判定<武器名>(<手>)`
  - ダメージ: `{攻撃ダイス}D6+{攻撃力の項目} ダメージ<武器名>(<手>)`
  - 項目: 右手は「右手命中」「右手攻撃力」、左手は「左手命中」「左手攻撃力」、合計は「命中」「攻撃力」
  - `<武器名>`: 行の武器の名前を、それぞれ `≪名前≫` にして並べる
  - `(<手>)`: 右手は「(右手)」、左手は「(左手)」、合計は付けない

```text
//--- 能動判定
{命中ダイス}D6+{右手命中}>? 命中判定≪試しの剣≫(右手)
{命中ダイス}D6+{左手命中}>? 命中判定≪試しの短剣≫(左手)
{攻撃ダイス}D6+{右手攻撃力} ダメージ≪試しの剣≫(右手)
{攻撃ダイス}D6+{左手攻撃力} ダメージ≪試しの短剣≫(左手)
```

### 能動判定の手の組み合わせ

- 適用範囲: 能動判定の行と、判定が命中判定のスキルの使う行
- 合計の行の武器: 武器を持つ手の武器を、右手、左手の順に（盾は入れない）
- 右手・左手の行の武器: その手が武器を持つなら、その武器。持たないならなし

#### 合計しないときの手の組み合わせ

- 適用範囲: 合計の仕方が「合計しない」のキャラクター
- 武器を持つ手ごとに、命中判定とダメージの行を作る（右手、左手の順）
- どちらの手も武器を持たない（素手や盾だけ）: 合計の 1 組

#### 両手を合計するときの手の組み合わせ

- 適用範囲: 合計の仕方が「両手を合計」のキャラクター
- 命中判定もダメージも、合計の 1 組

#### 命中のみ合計するときの手の組み合わせ

- 適用範囲: 合計の仕方が「命中のみ合計」のキャラクター
- 命中判定は合計の 1 行、ダメージは右手と左手の 2 行（武器を持たない手の分も作る）

#### 全部表示するときの手の組み合わせ

- 適用範囲: 合計の仕方が「全部表示」のキャラクター
- 命中判定もダメージも、右手、左手、合計の 3 行（武器を持たない手の分も作る）

### パレットのスキルの見出しのかたまり

- 適用範囲: 名前のあるスキル。名前のあるスキルが 1 つもなければ、このかたまりを作らない
- 最初に `//--- _/_/_/_/_/スキル_/_/_/_/_/` の行
- 「スキルのタイミングの見出し」ごとに `//--- 【見出し】` の行を作り、その下にスキルごとに、説明の行、使う行の順で並べる
- 見出しのかたまりの間に空行

#### スキルの説明の行

- 適用範囲: 名前のあるスキル
- `{スキル/見出し/項目}`: 欄のスキルの説明を、見出しをたどって読む
  - 名前の中の `/` は `\/`、`\` は `\\` にする

#### スキルの使う行

- 適用範囲: 名前のあるスキル
- 形: `<判定の部分> ≪スキル名≫<手> <コストの部分>`
  - スキル名は書かれたまま（「アックスに載せる文字」）
  - 部分が空なら、その部分と前後の空白を省く
- 判定の部分も、コストの部分も空なら、使う行を作らない
- タイミングに関わらず作る
- 判定の部分の既定: 空（ダイスを振らない）。自動成功、空欄、効果参照、「―」、自由に書いたもの
- `<手>` の既定: 空
- コストの部分: コストの数が 1 以上なら `:MP-コストLZ`。それ以外は空。装備によるコストの軽減は入れない

```text
{魔術判定ダイス}D6+{魔術判定}>=? ≪ヒール≫ :MP-4LZ
≪クイックヒール≫ :MP-5LZ
```

##### 判定が判定の選択肢のスキルの使う行

- 適用範囲: 判定の欄が、魔術判定・錬金術判定・呪歌判定・回避判定・筋力〜幸運のどれかのスキル
- 判定の部分: その判定の `>=?` の振り方
  - 筋力〜幸運は、能力値判定（例: 判定が「筋力」なら `{筋力判定ダイス}D6+{筋力判定}>=?`）
  - 回避判定は `{回避ダイス}D6+{回避}>=?`
- `{目標値}` の行は作らない。スキルは複雑で完全には作れないので、要る人は自分で足す

##### 判定が命中判定のスキルの使う行

- 適用範囲: 判定の欄が命中判定のスキル
- 能動判定の命中判定の行と同じ数だけ、使う行を作る
  - 判定の部分: その命中判定の振り方（`{命中ダイス}D6+{命中の項目}>?`）
  - `<手>`: その行の `(<手>)`。武器名は付けない
