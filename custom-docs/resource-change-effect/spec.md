# リソースの増減の演出の仕様書

- 目的: GM が、エネミーの HP や MP の減った量を、参加者の画面の設定に頼らずに伏せられるようにする
- フォーク元は、増減量の数字をどの項目の増減でも出す（`website/manual/character.md` の「ダメージと回復の演出」）が、このフォークでは、この仕様書を正とする
- 変えないもの: 閃光と震え、殴打・回復のエフェクト、効果音と、戦闘カットイン、チャットの行、頭上のバー、リプレイの動画に出る数字

## コマの上に浮かぶリソースの増減量の数字

- 適用範囲: 全部のコマと、その部位の、全部のリソースの項目
- 数字は、その項目の詳細設定の「増減でエフェクト」が入っているときだけ出す。一度もチェックを入れていない項目は、入っていない項目として扱う
- 1 回の操作で複数の項目が動いたときは、項目ごとに決める
- ほかの人が変えた増減にも同じ条件を当て、出るか出ないかは、どの人の画面でも同じにする
