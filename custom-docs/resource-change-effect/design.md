# リソースの増減の演出の設計書

- 仕様: `spec.md`
- フォーク元のファイルへの変更: `../fork-changes.md`

## リソースの増減の演出の設計の方針

- 新しい概念も設定も足さず、フォーク元にある「見せる変化」を、増減量の数字にも当てる
- 変えるのは、フォーク元の `src/app/features/character/game-character/piece-resource-changes.ts` の `show()` の、数字を積む行だけにする

## リソースの増減の演出の概念

| 概念                                                   | 意味                                                                                                                                                         | 変わるのは                 | 持たないもの           |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------- | ---------------------- |
| 変化のエフェクトの設定（`ResourceChange.playsEffect`） | その変化を、増減の大きさが分かる演出（増減量の数字と、規模の変わる殴打・回復のエフェクト）で見せるか。項目の属性 `cs-change-effect` が `true` のときだけ入る | 項目の「増減でエフェクト」 | 効果音の設定           |
| 見せる変化（`show()` の `shown`）                      | 1 回の操作の変化のうち、変化のエフェクトの設定が入ったもの                                                                                                   | 操作で動いた項目           | コマの反応             |
| コマの反応（`PieceResourceChanges.hitFlash`）          | ダメージか回復かだけを示し、増減の大きさを示さない閃光と震え。操作の変化の全部から決める                                                                     | 操作で動いた項目           | 変化のエフェクトの設定 |

### リソースの増減の演出の概念テスト

- GM がエネミーの HP の「増減でエフェクト」を外すと、その HP の変化は見せる変化に入らず、数字は浮かばない
- その HP が減ると、コマは閃光と震えで、ダメージを受けたことだけを示す

## リソースの増減の演出の仕様書の見出しと受け持ちの対応表

- 仕様を変えるときは、この表で直すファイルを決める

| 仕様書の見出し                         | 受け持ちの概念 | 受け持ちのファイル                                                    | 手伝い                                                                        |
| -------------------------------------- | -------------- | --------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| コマの上に浮かぶリソースの増減量の数字 | 見せる変化     | `src/app/features/character/game-character/piece-resource-changes.ts` | `src/app/domain/character/resource-feedback.ts`（「増減でエフェクト」を読む） |

## リソースの増減の演出のテストの作り

- 自分用のテスト `src/app/features/character/game-character/resource-change-effect-setting.spec.ts` が、仕様書の見出しの全部の項目を確かめる
- 「増減でエフェクト」の入り切りは、新しいコマの雛形の既定に頼らず、テストの中で、項目に値を書くか、属性のない項目を足して作る
- 変えないものは、フォーク元のテストが確かめる
