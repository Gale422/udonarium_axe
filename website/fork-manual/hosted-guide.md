# アプリから操作マニュアルを開く

このページは、遊んでいる画面から、この操作マニュアルを開く項目を説明します。
GM・PL・見学のだれでも使えます。

## 開きかた

1. 画面左上の丸いボタンを押します。
2. **表示**を押し、横に開いた小窓の、**メニューの編集**の下にある**操作マニュアル**（紙が重なったアイコン）を押します。

新しいタブで、この操作マニュアルの入口のページが開きます。
遊んでいる部屋のタブは、そのまま残ります。

**メニューの編集**で、置く場所を動かしたり、**GM ツール**や**PL ツール**に置いたりできます（→ [メニューを自分で組む](/manual/screen#メニューを自分で組む)）。
[ホットバー](/manual/hotbar)の枠にも入れられます。

## うまくいかないとき

| 見えるもの                                                           | 原因と直しかた                                                                                                                                                                                                    |
| -------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 画面左上の丸いボタンのメニューの**表示**に、**操作マニュアル**がない | **メニューの編集**の**Fav メニュー**で組み替えた並びに、**操作マニュアル**が入っていません。**項目を足す**で足すか、**初期配置に戻す**で戻します（→ [メニューを自分で組む](/manual/screen#メニューを自分で組む)） |
| スマホ版の画面の**メニュー**に、**操作マニュアル**がない             | スマホ版の画面の**メニュー**には出ません。**メニュー**の**パソコン版の画面を使う**で切り替えると、画面左上の丸いボタンのメニューから開けます                                                                      |
