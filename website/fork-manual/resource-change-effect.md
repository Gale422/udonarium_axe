# リソースの増減の数字

このページは、リソースが増えたり減ったりしたときにコマの上に出る増減の数字を、項目ごとに出すか決める設定を説明します。
GMが、エネミーのHPやMPがどれだけ減ったかを、参加者に伏せたいときに使います。
決めるのは、そのキャラクターのシートを直せる人（GMとPL）です。

## 増減の数字が出る項目

[ダメージと回復の演出](/manual/character#ダメージと回復の演出)には、リソースが変わるとどの項目でも増減の数字がコマの上に出るとありますが、数字が出るのは、項目の詳細設定の**増減でエフェクト**が入っている項目だけです。

- 1回の操作で複数の項目が動いたときは、項目ごとに出すか決まります
- ほかの人が変えた増減も同じです。数字が出るかどうかは、全員の画面で同じです

ほかの演出は、[ダメージと回復の演出](/manual/character#ダメージと回復の演出)のとおりに出ます。

- ダメージのときの閃光と震え、回復のときの光の輪
- 殴打と回復のエフェクト、効果音
- 戦闘カットイン、チャットの行、コマの上のバー、リプレイの動画に出る数字

## 数字を伏せる

1. 伏せたいキャラクターのコマを右クリックし、**詳細を表示**を選びます。
2. 伏せたいリソースの項目がある見出しの右の鉛筆（**編集**）を押し、その項目の行の**詳細設定**を開きます（→ [種別の変えかた](/manual/data-element#種別の変えかた)）。
3. **増減でエフェクト**のチェックを外します。

その項目が増えても減っても、数字は出なくなります。
ダメージのときの閃光と震えと、回復のときの光の輪は残るので、ダメージを受けたか回復したかは伝わります。

## 設定の項目

| 項目                 | 既定値                                                                                         | 内容                                                                                   |
| -------------------- | ---------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| **増減でエフェクト** | 項目による（→ [項目ごとのエフェクトと効果音](/manual/character#項目ごとのエフェクトと効果音)） | 入れると、増減の数字が出て、殴打・回復のエフェクトも出せます。外すと、どちらも出ません |

## うまくいかないとき

| 見えるもの                                           | 原因と直しかた                                                                                                                                                                                         |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| HPが減っても、数字が出ない                           | その項目の**増減でエフェクト**が外れています。数字を出したい項目に入れます。どの項目に最初から入っているかは、[項目ごとのエフェクトと効果音](/manual/character#項目ごとのエフェクトと効果音)にあります |
| **増減でエフェクト**を外したのに、コマが光る・震える | ダメージのときの閃光と震えと、回復のときの光の輪は、ダメージか回復かを示すために、いつも出ます                                                                                                         |
| 数字を伏せたのに、減った量が分かってしまう           | チャットの行（`:HP-10`の発言など）や、コマの上のバーには、増減がそのまま出ます。バーは項目ごとに出さないようにできます（→ [コマにHPバーを出す](/manual/character#コマにhpバーを出す)）                 |
