# アリアンロッド2Eのキャラクターの取り込み

このページは、ゆとシートかキャラクター保管所で作ったアリアンロッド2EのPCを、そのまま遊べる欄とチャットパレットを持つコマにする取り込みを説明します。
どちらのサイトから取り込んでも、判定・ダメージ・リソース操作・バフ・スキルの行がそろった同じコマが、テーブルに置かれます。
GMとPLが使えます。見学は使えません。

## 取り込む

取り込みパネルの開きかたは、[取り込みパネルを開く](/manual/character-import#取り込みパネルを開く)にあります。
取り込みパネルの入力欄に、ゆとシートかキャラクター保管所のキャラクターページのアドレスを貼って**取り込む**を押すと、このページのコマになります。

取り込めるのは、ゆとシートのアリアンロッド2EのPCのシートと、キャラクター保管所のアリアンロッド2Eのシートです。
ゆとシートのエネミーやギルドのシートと、ほかのゲームのシートは、[キャラクターの取り込み](/manual/character-import)のとおりに取り込まれ、このページのコマにはなりません。

::: tip 自分でゆとシートを置いているサイトのキャラクターは、データを貼ります
アドレスから取り込めるのは、yutorize.workとyutorize.2-d.jpに置かれたゆとシートのキャラクターです。
ほかのサイトに置かれたゆとシートのキャラクターは、ページのアドレスの最後に`&mode=json`を足して開き、出た文字を全部コピーして、取り込みパネルに貼ります。
:::

::: tip 成長したら取り込み直します
コマの値は、取り込んだときのシートの値です。ゆとシートやキャラクター保管所で成長させたら、もう一度取り込みます。
:::

## 取り込まれるコマ

コマの名前と発言の色は、シートのものになります。ダイスボットは、アリアンロッドのものになります。
キャラクター保管所のシートは、キャラクター名が空なら、シートの題名がコマの名前になります。発言の色は付きません。

### コマの欄

| 欄             | 中身                                                                                                                         |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| リソース       | HP・MP・フェイト（今の値と最大値）、フェイト使用上限、行動値、移動力、物理防御力、魔法防御力                                 |
| 能力値         | 筋力・器用・敏捷・知力・感知・精神・幸運の、基本値と能力値                                                                   |
| 判定           | 能力値判定と、トラップ探知・トラップ解除・危険感知・エネミー識別・アイテム鑑定・魔術・呪歌・錬金術の判定の、ダイス数と固定値 |
| 戦闘           | 命中・攻撃・回避のダイス数と値、右手と左手の命中と攻撃力                                                                     |
| スキル         | タイミングごとに、スキルの説明（名称・取得元・分類・SL・タイミング・判定・対象・射程・コスト・使用条件・効果）               |
| 携行品・所持品 | 所持金と、携行品・所持品の内容                                                                                               |
| 誓約           | 誓約ごとに、成長点と、恩恵・束縛など                                                                                         |
| コネクション   | 相手ごとに、関係と備考                                                                                                       |
| プロフィール   | PL・CL・種族・性別・年齢・クラス・所属ギルド・容姿や経歴のメモ・取り込んだシートのアドレス                                   |

- 判定と戦闘のダイス数と値は、シートに出ている合計です。シートで判定ごとに足したダイス数や修正も入ります。シートにない値は、[キャラクター保管所のシートの欄](#キャラクター保管所のシートの欄)のとおりに入ります
- スキル・誓約・コネクションの欄は、シートに書いてあるものだけ作ります
- コマにマウスを乗せると、リソースの欄の項目がまとめて出ます
- HPとMPは、**増減でエフェクト**が入っているので、増えたり減ったりすると、増減の数字がコマの上に出ます（→ [リソースの増減の数字](/fork-manual/resource-change-effect)）
- 移動力は、単位をmにして入ります。移動範囲で何マスになるかは、**部屋設定**の**マスの単位**と**1 マスの距離**で決まります（→ [単位の換算](/manual/move-range#単位の換算)）

#### キャラクター保管所のシートの欄

キャラクター保管所のシートにない値は、次のように入ります。キャラクター保管所のシートには能力値判定の欄がないので、能力値判定はいつもこの値です。

| 値                                                                   | 入る値                                                                  |
| -------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 能力値判定のダイス数と固定値                                         | ダイス数は2、固定値はその能力値                                         |
| 使わない魔術・呪歌・錬金術の判定（作成画面でチェックのない判定など） | ダイス数は2、固定値は元の能力値（魔術は知力、呪歌は精神、錬金術は器用） |
| フェイト使用上限                                                     | 幸運の能力値                                                            |
| PL・称号クラス・所属ギルド、コネクションの備考                       | 空                                                                      |
| 誓約                                                                 | 作りません                                                              |

- スキルは、種族スキル、最初のメインクラスのスキル、スキル、一般スキルの順に入ります
- 携行品・所持品の内容は、所持品の表の1行が、`名称[重量:…][価格:…][効果・備考など:…]`の1行になって入ります。空の項目は入りません

### チャットパレット

パレットは、シートの値から作ります。上から次の見出しの順に並びます。

| 見出し             | 行                                                                                                                   |
| ------------------ | -------------------------------------------------------------------------------------------------------------------- |
| 判定               | 能力値判定と特殊な判定。目標値を`?`にしてあるので、成功と失敗は出ず、クリティカルとファンブルだけが出ます            |
| 判定（目標値）     | 同じ判定を、`{目標値}`と比べる行                                                                                     |
| 受動判定           | 回避判定と、物理・魔法・貫通のダメージをHPに当てる行。ダメージは行に書き足します。物理と魔法は防御力を引いて当てます |
| 受動判定（目標値） | 同じ行を、`{目標値}`を使う形にした行。回避判定は`{目標値}`と比べ、ダメージの行は`{目標値}`をダメージにして当てます   |
| リソース操作       | フェイトの使用、HPとMPの全回復、HPポーションとMPポーション                                                           |
| バフ操作           | バフを付ける行と外す行のひな形と、バッドステータスを付ける行と外す行                                                 |
| 能動判定           | 命中判定とダメージの行。右手と左手の合計の仕方に合わせて、手ごとの行や、両手の合計の行を作ります                     |
| スキル             | タイミングごとに、スキルの説明を送る行と、スキルを使う行（判定と、MPのコストの支払い）                               |

- 行を押すと、まず入力欄に入ります。ダメージを書き足す行や、書き換える行は、入力欄で直してから送ります（→ [行をクリックして送る](/manual/chat-palette#行をクリックして送る)）
- HPやMPを動かす行は、0と最大値の間で止まります
- 「（目標値）」の付いた見出しの行は、このタブで振られた結果か、GMが示した目標値を読みます（→ [振られた結果を目標値にする](/manual/chat-syntax#振られた結果を目標値にする)）。使わないほうの見出しは、行ごと消してかまいません
- 毒と衰弱を付ける行は、`n`を強さに書き換えて送ります。ラウンドの終わりごとに、HPが強さ×5減ります
- 行の書きかたは、[チャットの特殊記法](/manual/chat-syntax)と[バフ／デバフ](/manual/buff)にあります

#### 右手と左手の合計の仕方

| シート             | 合計の仕方                                                                                                                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ゆとシート         | シートの右手と左手の合計の仕方（合計しない・両手を合計・命中のみ合計・全部表示）のとおり                                                                                                   |
| キャラクター保管所 | 右手と左手の種別が同じシートは全部表示で、右手・左手・合計の行を作ります。ほかのシートは合計しないで、武器を持つ手ごとの行を作ります。どちらの手も武器を持たないときは、合計の行を作ります |

#### スキルの見出しと、スキルを使う行

- スキルの見出しは、シートに書かれたタイミングで分けます。キャラクター保管所で選べる「パッシヴ」「ｾｯﾄｱｯﾌﾟ」「DR直前」などは、「パッシブ」「セットアップ」「DRの直前」とは別の見出しになります
- スキルを使う行に判定のダイスが入るのは、判定が「命中判定」「回避判定」「魔術判定」「呪歌判定」「錬金術判定」か、能力値の名前のスキルです。キャラクター保管所で選べる「魔術」「命中」のスキルの行には、判定のダイスが入りません

### 取り込まないもの

- ゆとシートで自分で書いたチャットパレット。パレットは、いつもシートの値から作ります。自分のパレットを使いたいときは、ゆとシートのコマ出力（zip）を読み込みます（→ [保存と読み込み](/manual/save-load)）
- 画像。ほかのシートの取り込みと違い、キャラクター保管所のシートの画像も取り込みません。取り込んだあとに設定します（→ [画像](/manual/images)）
- 装備の欄と、ゆとシートの追加ステータス
- キャラクター保管所のライフパス、成長と経験点の記録、身長・体重・髪・瞳・肌の色
- スキルの使用回数（「シーン1回」など）を数える欄。回数の決まりは、スキルの説明に書かれたまま入ります

## うまくいかないとき

| 見えるもの                                                     | 原因と直しかた                                                                                                                                                                                                                                                                                                                                    |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 欄とチャットパレットの少ないコマになる                         | アリアンロッド2EのPCのシートではありません。ゆとシートのエネミーやギルドのシートは、[キャラクターの取り込み](/manual/character-import)のとおりに取り込まれます                                                                                                                                                                                    |
| パレットの行を押しても、ダイスが振られない                     | 欄と同じ名前のバフを付けている間は、その欄を名前で読めません。バフの名前を変えるか、バフを外します。値は変わっていません                                                                                                                                                                                                                          |
| キャラクター保管所のシートの、判定や命中判定の行で、値が抜ける | シートの値に、全角の数字のような、数として読めない字が書かれているか、値がありません。盾だけを持つシートなど、右手と左手の種別が違い、どちらも武器でないシートには、命中と攻撃力の合計の値がありません。シートを直して取り込み直すか、行に値を書き足します                                                                                        |
| スキルの説明の行を押しても、説明が出ない                       | 同じタイミングに同じ名前のスキルが2つある、名前に`{`か`}`がある、名前が`^`で終わる、名前が空白だけ、などです。シートでスキルの名前を直し、取り込み直します                                                                                                                                                                                        |
| スキルの説明を送ると、演出が出る                               | 送った文の中で最初に《》に囲まれた名前と同じ名前のエフェクトが、**エフェクト集**にあります（→ [マップ演出（エフェクト）](/manual/map-effects)）。シートの文をそのまま取り込むので、出したくないときは、シートで文を直します                                                                                                                       |
| **取得に失敗しました**などと出て、取り込めない                 | [キャラクターの取り込みのうまくいかないとき](/manual/character-import#うまくいかないとき)にあります                                                                                                                                                                                                                                               |
| **対応していないURLです**と出て、取り込めない                  | アドレスから取り込めるのは、yutorize.workとyutorize.2-d.jpのゆとシートと、キャラクター保管所のキャラクターページです。ほかのサイトに置かれたゆとシートは、データを貼ります（→ [取り込む](#取り込む)）。ココフォリアのコマのデータを貼ると、[キャラクターの取り込み](/manual/character-import)のとおりに取り込まれ、このページのコマにはなりません |
| HPなどを動かす行や判定の行が、まとめて動かない                 | 欄と同じ名前（HPなど）か「目標値」という名前のスキルがあると、その名前を読む行が、すべて動きません。シートでスキルの名前を変えて、取り込み直します                                                                                                                                                                                                |
| スキルの説明を送ると、文の一部が数に変わったり、消えたりする   | 説明の文の中の`{`と`}`に囲まれた所は、欄の値などを読む参照として読まれます（→ [チャットの特殊記法](/manual/chat-syntax)）。シートで文を直して、取り込み直します                                                                                                                                                                                   |
| バッドステータスを付ける行で、思っていたのと違う効果が付く     | 部屋の状態異常の一覧に同じ名前があると、一覧の中身で付きます。新しい部屋の一覧には、「命中-2」の恐怖があります。部屋の一覧の状態異常を書き換えるか消します（→ [状態異常を登録して表から付ける](/manual/buff#状態異常を登録して表から付ける)）                                                                                                     |
